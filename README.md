## Project Overview

Maine Makers Workshop is a responsive, multi-page website designed to promote a community makerspace in Bangor, Maine. The website allows visitors to explore hands-on workshops, learn about the makerspace, view membership options, and find contact information. It features workshop listings with sorting options, membership pricing, responsive navigation, and a clean, user-friendly design. The goal of the project is to make creative learning and shared workspace opportunities easy to discover and accessible to the local community.

## Developer Notes

-The website uses HTML, CSS, and JavaScript.
-Styles are maintained in css/style.css.
-JavaScript functionality is maintained in js/script.js.
-JavaScript is loaded using the defer attribute.
-The website uses a consistent layout and shared navigation across its pages.
-Workshop listings contain sample project data. Dates and seat counts are not connected to live availability.
-Images are stored in the website's images directory.
-The website is designed to work across modern desktop and mobile browsers.

## Website Features
-Home Page: Introduces the makerspace and highlights its purpose and offerings.
-About Page: Provides information about the makerspace and its community.
-Workshops Page: Displays available workshops with descriptions, dates, prices, durations, and available seats.
-Workshop Sorting: Allows visitors to sort workshops by default order, lowest price, or highest price.
-Memberships Page: Displays membership options, including Day Pass, Monthly Maker, and Unlimited Maker, with pricing and descriptions.
-Contact Page: Provides contact information for visitors.
-Responsive Navigation: Includes a mobile-friendly navigation menu that adapts to smaller screens.
-Images and Styling: Uses custom images, consistent colors, rounded image corners, and a clean layout to create a welcoming experience.

## Accessibility Features
-Semantic HTML: Uses appropriate HTML elements to organize content and improve screen reader compatibility.
-Image Alt Text: Provides alternative text for meaningful images so visitors using screen readers can understand their content.
-Responsive Design: Supports different screen sizes, including mobile phones, tablets, and desktop computers.
-Accessible Navigation: Uses clearly labeled navigation links and a mobile menu.
-Form Labels: Uses descriptive labels for interactive form elements where applicable.
-Readable Typography: Uses clear fonts, appropriate spacing, and contrasting text and background colors.
-Keyboard Accessibility: Supports keyboard navigation for interactive elements.
-Status Messages: Uses an aria-live region to announce workshop sorting updates to assistive technologies.
